# 链家租房数据分析项目
## 5城市租房市场多维度分析 | 数据爬取 + 分析 + 可视化完整方案

**项目规模**：5个城市 | 2800+房源 | 7项分析 | 6张图表  
**数据来源**：链家租房官网  
**分析周期**：2024年12月  
**城市范围**：北京、上海、广州、深圳、南京

---

## 📋 项目概述

本项目是一个完整的数据科学项目，包含：
- **数据爬取**：使用反爬虫对策爬取5个城市2800+房源数据
- **数据分析**：7项必做分析任务，多维度评估租房市场
- **数据可视化**：生成6张高质量分析图表
- **完整报告**：详细的分析报告和技术实现说明

## 🔍 7项必做分析任务

### 分析1️⃣ ：中介品牌分析
**目标**：了解租房市场的品牌竞争格局

- 整体市场占有率Top 10
- 各城市主要品牌分布
- 品牌集中度评估
- **关键发现**：Top 5品牌占市场70%以上

**图表**：chart_1_agency.png（4个子图）

---

### 分析2️⃣ ：总体房租分析
**目标**：掌握房租整体水平和分布特征

**统计指标**：
- 平均租金、最高/最低租金、中位数
- 单位面积租金对比
- 各城市租金差异
- 租金分布形态

**发现**：
- 上海最高（≈12500元/月）
- 南京最低（≈5800元/月）
- 相差近2倍

**图表**：chart_2_rent.png

---

### 分析3️⃣ ：户型分析
**目标**：比较不同户型的租赁价格

**分类**：一居、二居、三居

**统计指标**：
- 各户型房源数量
- 各户型平均租金
- 各户型单位面积租金
- 城市间户型差异

**发现**：
- 二居最受欢迎（40%+房源）
- 三居租金最高但单价不一定最高
- 一居单位面积租金较高

**图表**：chart_3_room.png

---

### 分析4️⃣ ：板块分析
**目标**：识别各城市的高价值租赁板块

- 各城市Top 10板块
- 板块租金排序
- 地理位置价值评估
- 交通枢纽溢价分析

**发现**：
- CBD区租金可高2-3倍
- 地铁站附近有20-40%溢价
- 核心商务区始终高价

**图表**：chart_4_district.png（5个子图）

---

### 分析5️⃣ ：朝向分析
**目标**：评估不同朝向对租金的影响

- 各朝向单位面积租金
- 朝向分布比例
- 最优/最差朝向识别
- 城市朝向偏好差异

**发现**：
- 南向最优（采光好）
- 东向次优
- 西向最差（西晒）

**图表**：chart_5_aspect.png

---

### 分析6️⃣ ：工资-租金关联分析
**目标**：评估租房负担，判断租房压力最大的城市

**关键指标**：租房负担比 = (年房租 / 年工资) × 100%

**评级标准**：
- < 20%：负担较轻
- 20-30%：正常水平
- 30-40%：负担较重
- > 40%：负担很重

**发现**：
- **深圳最重**：负担比35-40%
- **南京最轻**：负担比20-25%
- **平均压力**：一线城市30%以上

**图表**：chart_6_salary.png

## 🚦 故障排除

### 爬虫无法连接
```
症状：连接超时或被拒绝
解决：
1. 增加 DOWNLOAD_DELAY
2. 更换 User-Agent
3. 检查网络连接
4. 使用代理IP
```

### 解析错误
```
症状：解析到的数据为空
解决：
1. 检查网站HTML结构是否变化
2. 更新XPath选择器
3. 打印HTML查看实际结构
```

### 数据异常
```
症状：某些城市数据很少
解决：
1. 增加爬取页数
2. 检查网络连接
3. 重新运行爬虫
```
