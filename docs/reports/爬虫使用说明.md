# 链家新房+二手房爬虫 - 使用说明

## 项目概述
使用Selenium + BeautifulSoup爬取链家官网新房（第3-7页）和二手房（第3-7页）数据，共5页，每个数据文件包含数据条目。

## 爬虫特性

### 核心反爬虫对策
1. **隐藏自动化特征**：禁用`AutomationControlled`标签，隐藏`navigator.webdriver`属性
2. **随机User-Agent**：轮换多个浏览器标识，模拟真实用户
3. **智能等待**：动态延迟2-7秒，避免规律性访问
4. **重试机制**：单页最多重试3次，每次间隔45秒
5. **登录检测**：自动识别并等待用户完成登录（最长2分钟）

### 解析策略
- **多选择器支持**：支持多种HTML结构变化
- **正则表达式提取**：灵活提取价格、面积、房型等信息
- **容错机制**：缺失字段默认标记为"未知"

## 数据字段

### 新房字段
| 字段 | 说明 |
|------|------|
| name | 楼盘名称 |
| house_type | 房屋类型（公寓/别墅/洋房/商住/普通住宅） |
| location | 地点（区+板块） |
| room_type | 房型（如：2居2厅） |
| area | 面积（单位：㎡） |
| unit_price | 单价 |
| total_price | 总价 |

### 二手房字段
| 字段 | 说明 |
|------|------|
| community_name | 小区名称 |
| location | 地点（区+板块） |
| room_type | 房型（不拆分） |
| unit_price | 单价 |
| total_price | 总价 |

## 使用方式

### 环境要求
```bash
pip install selenium beautifulsoup4 lxml
```
需要下载Chrome WebDriver：https://chromedriver.chromium.org/

### 运行爬虫
```bash
cd lianjia_spider
python improved_spider.py
```

### 执行流程
1. 初始化Chrome驱动（含反爬虫设置）
2. 访问链家新房首页
3. 若需登录，自动等待用户完成登录（浏览器中操作）
4. 循环爬取第3-7页数据
5. 解析HTML并提取信息
6. 保存为JSON格式：`new_houses.json`、`second_houses.json`

## 输出文件
- **new_houses.json**：新房数据（JSON格式）
- **second_houses.json**：二手房数据（JSON格式）

## 注意事项
- 爬虫需要真实浏览器环境，不支持无头模式
- 若出现登录界面，请在60秒内在浏览器中完成登录
- 建议在非高峰时段运行爬虫
- 单页解析失败会自动重试，最多3次

## 技术栈
- **爬虫框架**：Selenium 4.x
- **解析库**：BeautifulSoup4 + lxml
- **编程语言**：Python 3.7+
